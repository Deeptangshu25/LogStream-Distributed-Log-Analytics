# LogStream – Distributed Log Analytics & Alerting Platform

A distributed log analytics and alerting platform built with Java, gRPC, Apache Lucene, React, ECharts, and WebSockets.

## Project Overview

LogStream is designed to ingest, index, search, analyze, and monitor large volumes of application logs.

## Technology Stack

- Java
- Spring Boot
- gRPC
- Apache Lucene
- React
- ECharts
- WebSockets
